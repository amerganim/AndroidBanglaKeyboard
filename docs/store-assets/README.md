# Play Store assets

Ready-to-upload graphics for the Google Play listing.

| File | Use | Size |
|---|---|---|
| `icon-512.png` | App icon (high-res) | 512×512 |
| `feature-1024x500.png` | Feature graphic | 1024×500 |

These are clean, brand-matched placeholders generated from the app's colors
(indigo `#5B5BD6`) and the keyboard mark. Replace with a professionally designed
version any time — the requirements (sizes) stay the same.
